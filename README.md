# manifests

Machine-written update manifests. **Do not merge anything into this branch, and
do not edit these files by hand.**

`stable.json` and `beta.json` are regenerated by the release workflow every time
a release is published, and are what installed copies of the plugin poll to
decide whether an update is waiting.

This branch is deliberately orphaned and outside the release flow. If the
manifests lived on `main` and `develop` instead, merging `develop` into `main`
would briefly publish a beta version to every site on the stable channel — which
is exactly what having two channels is meant to prevent.

Each manifest names the channel it belongs to, and the plugin ignores a manifest
whose channel does not match the site's own.
